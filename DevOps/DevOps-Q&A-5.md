## 1. Handling Deployment Failures 

**Question:** How do you handle a deployment failure? 
**Answer:** 

When a deployment fails, my first step is to review the logs and error messages to identify the root cause. I check for common issues such as misconfigurations, network
problems, or code errors. If the issue is identified quickly, I resolve it and redeploy. If not, T roll back to the previous stable version to minimize downtime. Afterward, I perform a thorough root cause analysis and update our deployment process or scripts to prevent similar issues in the future.
